# 개인정보·보안 요구사항

## 개인정보·보안·학교 환경 확인

교육용 프로그램일 가능성이 있으므로 관련이 있을 때 다음 사항을 반드시 확인한다.

- 학생 이름
- 학번
- 연락처
- 성적
- 출결
- 상담 기록
- 사진과 영상
- 건강 정보
- 학부모 정보
- 미성년자 개인정보
- 외부 AI 서비스로 전송되는 정보
- 학교 또는 교육청의 보안 정책
- 자료 보관 기간
- 자료 삭제 방법
- 사용자별 접근 권한
- 관리자 접근 범위
- 백업과 복구
- 학교 내부망 사용 여부
- 공개 인터넷 서비스 여부

다음 원칙을 적용한다.

- 필요한 개인정보만 최소한으로 수집한다.
- 수집 목적이 분명하지 않은 정보는 저장하지 않도록 제안한다.
- 역할별로 필요한 정보만 열람하게 한다.
- 학생 개인정보를 개발용 예시나 로그에 그대로 넣지 않도록 한다.
- 실제 학생 정보 대신 가상 데이터로 시제품을 만들 수 있는지 확인한다.
- 비밀번호, API 키, 비밀값을 소스코드에 직접 작성하지 않도록 명세한다.
- 중요한 작업에는 입력 검증과 권한 확인을 요구한다.
- 개인정보가 로그, 오류 메시지 또는 URL에 노출되지 않도록 고려한다.
- 외부 AI 서비스로 전송되는 데이터와 그 필요성을 명확히 한다.
- 자료 삭제와 계정 삭제 시 처리 방식을 정한다.
- 백업 자료의 보관 및 삭제도 고려한다.

법률, 규정 또는 기관 정책을 확정적으로 단정하지 않는다.

확인이 필요한 법적·정책적 사항은 다음과 같이 표시한다.

- 확인이 필요한 사항
- 확인해야 할 담당자 또는 기관
- 확인 전에는 사용하지 말아야 할 기능
- 개인정보를 제외하고 시제품을 만드는 대안

이 스킬은 설계 단계의 개인정보·보안 검토를 지원하지만 다음을 대체하지 않는다고 명확히 한다.

- 법률 전문가 검토
- 학교 또는 교육청의 공식 보안 승인
- 실제 소스코드 보안 감사
- 클라우드 보안 설정 점검
- 모의해킹 또는 침투 테스트

보안 요구사항은 다음 세 단계로 구분한다.

1. 개발 전에 확인할 사항
2. 개발 중 구현할 사항
3. 배포 전에 검증할 사항

## 설계에 남길 검증 가능한 조건
- 개발 전: 수집 목적·최소 필드·학생/미성년자 여부·담당 기관 정책·외부 전송·보관 기간·권한과 승인 미확인 기능을 기록한다. 실제 개인정보를 대화로 요청하지 말고 항목과 구조를 묻는다.
- 개발 중: 서버 측 입력값/파일 검증, 사용자 및 객체별 최소 권한, 제한된 CORS 출처, 안전한 세션·비밀번호 처리, 비밀값 환경변수·비밀 저장소 관리, 전송·저장 암호화와 키 분리를 요구한다. 비밀번호는 복호화 가능한 저장 대신 적절한 해시 또는 관리형 인증을 사용한다. 클라이언트에 전달되는 환경변수는 비밀 저장소가 아니다.
- 로그·오류·URL·코드·테스트에서 평문 개인정보를 제외한다. 합성 식별자(예: SYN-STUDENT-001)와 가상 점수를 사용한다. 비식별화만으로 재식별 위험이 사라진다고 단정하지 않는다. 분석 데이터의 필요 필드를 최소화한다.
- 배포 전: 다른 사용자/학급의 조회·수정 차단, 민감 파일 URL 비공개, 비밀값 노출, CORS, 로그 비식별화, 삭제·백업 복구 및 접근성 검증을 인수 조건으로 연결한다.
- 보관 만료·계정 삭제 시 본문, 첨부, 캐시, 감사 기록과 백업 처리의 범위·기한·예외를 정한다. 백업 접근권한·암호화·보관기간·복구 후 삭제 자료 재등장을 검토한다.
- AI 전송은 목적·최소 입력·비식별화·제공자 보관 및 학습 정책·검토 담당자·정확성·비용·실패 대안을 확인한다. 미확인 정책은 확정하지 않고 실제 정보 사용 전 확인 조건으로 남긴다.
- 라이브러리/서비스의 출처, 유지관리, 라이선스, 알려진 취약점, 데이터 위치와 불필요한 의존성을 검토한다. 새 의존성은 구체적 필요가 있을 때만 제안한다.
검토 기록은 위험 / 영향받는 데이터 / 요구사항 / 검증 방법 / 확인 담당자 / 미결정 사항으로 구성한다. 보안 수준은 시제품과 실사용을 구분하되 학생 개인정보를 쓰는 시제품의 보호를 생략하지 않는다.
