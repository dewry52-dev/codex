# 디자인

산호색 여우 탐험가 단비, 또렷한 파란 글씨, 밝은 하늘색과 크림색 바탕, 주황색 행동 버튼. 단비는 큼직한 귀와 머리, 단순한 의상, 진한 남색 윤곽선과 흰 외곽 테두리로 작은 게임 화면에서도 구별되도록 합니다. 게임에서는 96×102 크기로 표시하고 머리 위 이름표를 붙입니다. 파란 궁궐 지붕, 선명한 초록 잔디, 보라색 역사 문, 분홍·노랑 꽃 장식으로 화사한 탐험 분위기를 만듭니다. 큰 여백과 읽기 쉬운 화면. 원본 앱의 훈장 캐릭터나 화면을 재사용하지 않습니다.

핵심 화면은 횡스크롤 플랫폼 게임입니다. 조선풍 궁궐, 산과 구름의 배경, 발판, 코인, 돌멩이 장애물, 다섯 역사 문으로 구성합니다. 단비를 직접 움직이고 점프하며 문제를 만나게 합니다. 퀴즈는 탐험을 잠시 멈추는 역사 문 대화상자로 연결합니다.

캐릭터는 달릴 때 발을 바꾸는 4프레임 순환 동작을 사용합니다. 점프는 70ms 웅크리기, 공중에서 팔·다리 펼치기, 150ms 착지 압축 후 복귀 순서입니다. 대기·달리기·점프의 발바닥 기준선을 맞추고, 모션 변화로 충돌 상자를 확대하지 않습니다.

개인 모드는 태블릿/모바일/PC 반응형, 교실 모드는 큰 문제와 답안. 이동·점프 터치 버튼 최소 44px, 키보드 조작과 포커스, 상태 알림, 명시적 일시정지와 창 전환 시 자동 정지를 지원합니다. 화면 전환 효과는 최소화합니다. 실시간 게임 자체에는 이동 애니메이션이 필요합니다. 개인정보 입력 없이 사용합니다.
