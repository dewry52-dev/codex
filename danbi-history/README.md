# 단비의 시간탐험대

초등 5학년을 위한 세종·훈민정음 횡스크롤 플랫폼 게임. 단비를 직접 이동하고 점프하며 코인을 수집합니다. 발판, 물 틈, 움직이는 돌멩이, 체크포인트, 역사 문 5개, 유물 목표, 개인/교실 모드를 지원합니다.

순수 HTML/CSS/JavaScript. 서버, 계정, 데이터베이스, 분석 추적, 로컬 저장소 없이 현재 페이지 메모리로만 진행합니다. 새로고침 시 초기화합니다. 교실 모드는 교사의 한 화면을 공유하는 방식이며 기기 동기화가 아닙니다.

dist 디렉터리를 정적 HTTP 서버로 제공합니다(ES 모듈이므로 파일을 직접 여는 방식은 지원하지 않습니다). 방향키/A/D 이동, Space/위 화살표/W 점프, E 역사 문, P 일시정지. 터치에서는 방향 버튼과 점프를 동시에 누를 수 있습니다. 코인과 열린 문은 피해 후에도 유지되며 체크포인트에서 재시작합니다. 세 생명을 모두 쓰면 생명이 회복되어 학습을 계속할 수 있습니다.

단비는 산호색 여우 탐험가입니다. 흰 외곽선과 큰 머리·귀로 배경과 구분하며 약 100px 높이와 이름표로 표시합니다. 기존 수달 시안은 assets/danbi.png에 보존합니다. 대기는 assets/danbi-fox.png, 애니메이션은 assets/danbi-motion.png를 사용합니다. 달리기는 발 위치가 달라지는 4프레임을 반복하고, 점프 전 70ms 웅크리기 → 공중에서 펼치기 → 착지 후 150ms 압축 동작으로 이어집니다. poses.mjs의 실측 원본 좌표로 각 동작을 잘라 사용하여 발바닥을 맞춥니다. 방향 전환도 지원합니다. 궁궐과 코인 등 배경은 Canvas로 그립니다. 시간여행과 유물 분실은 창작, 역사 학습 내용은 앱 내부 출처를 참고하세요.

검증: `node --test engine.test.mjs`로 코인 중복 수집 방지, 닫힌 문 차단, 점프/발판 착지, 추락 체크포인트, 실제 입력으로 전체 레벨 통과를 검사합니다.

배경 음악: `make_music.py`에서 새로 작곡한 132 BPM의 약 29초 반복 음악을 합성합니다. 외부 곡이나 음원 샘플을 사용하지 않습니다. 탐험 시작 시 기본 재생, 음악 버튼으로 배경 음악과 효과음 음소거, 퀴즈에서는 낮은 음량, 일시정지/안내 창/탭 숨김/완료 화면에서는 정지합니다. 브라우저가 재생을 차단하면 음악 버튼으로 다시 시도할 수 있습니다.

화사한 하늘색, 초록 잔디, 파란 궁궐 지붕, 보라색 역사 문과 꽃 장식으로 게임 팔레트를 구성합니다.
